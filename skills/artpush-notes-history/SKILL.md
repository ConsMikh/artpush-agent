# Заметки, история и события картины в ArtPush

## Назначение

Лента заметок картины, история её изменений и офлайн-события с датой. Общие правила, коды выхода и
ключ — в скилле `artpush`.

## Заметки

```sh
artpush notes list 184 --table
artpush notes add 184 "Писала в июне после поездки в Кыштым"
artpush notes edit 184 31 "Писала в июле после поездки в Кыштым"   # номер заметки — из notes list
artpush notes delete 184 31
```

Править и удалять можно только свои заметки; чужая — ошибка прав, не обходи её. Добавляй и правь по
прямой просьбе; если текст заметки сочинил ты — покажи его человеку и спроси перед добавлением.
Удаление заметки — сначала назови номер и текст, дождись «да».
Найти картины по словам из заметок: `artpush paintings search --note "слова"` (скилл `artpush-search`).

## История

```sh
artpush history 184 --table
```

Каждая запись — кто, когда, что изменено. Правки по ключу помечены «через агента · ключ «…»», импорт —
своим источником. Так можно проверить, что сделал агент, и ответить «кто поменял статус».

## События задним числом

```sh
artpush events add 184 --type Выставка --date 2024-05-12 --comment "Галерея «Арка», Екатеринбург"
```

- `--date` — ГГГГ-ММ-ДД. Точной даты нет — спроси человека, не выдумывай.
- `--type` — тип по имени из справочника. **Нового типа нет — утилита его заведёт.** Перед этим сверь
  с имеющимися (опечатка «Выставко» создаст лишний тип): если похожего нет, спроси человека, заводить ли
  новый тип «…».

## Ошибки

- `usage` (код 1): дата не в формате ГГГГ-ММ-ДД.
- Код 3: ключ только для чтения — добавлять нельзя, скажи человеку.
