# Каталоги в ArtPush

## Назначение

Каталоги — дерево папок для картин; картина может лежать в нескольких каталогах сразу.
Общие правила, коды выхода и ключ — в скилле `artpush`.

## Дерево

```sh
artpush catalogs tree --table
```

Номера каталогов из дерева нужны для `artpush paintings search --catalog`, массового заполнения и импорта.

## Создать и наполнить

```sh
artpush catalog add "Выставка 2024"
artpush catalog add "Акварели" --parent 12
artpush catalog members 12 --add 101,118,184
artpush catalog members 12 --remove 118
```

- Перед созданием проверь дерево: каталога с таким именем может уже быть. Имя спорное — спроси человека.
- Добавление в каталог не убирает картину из других каталогов.
- Создание и смена состава по прямой просьбе подтверждения не требуют; если состав выбрал ты (например,
  по поиску) — покажи список картин и спроси «Добавить эти N картин в «…»? (да / нет)».

## Удаление каталога — только с подтверждением

```sh
artpush catalog delete 12 --preview --table
# показать человеку: какие каталоги ветки уходят в корзину и сколько в них картин; спросить «Удалить? (да / нет)»
artpush catalog delete 12 --apply pv_…
```

- Удаляется вся ветка (подкаталоги тоже), каталог уходит в корзину — восстановить:
  `artpush trash restore --catalog 12` (скилл `artpush-trash`).
- Жетон одноразовый, 10 минут; после ошибки — новый `--preview` и новый вопрос.

## Чего нет у утилиты

Переименование и перенос каталога в другое место дерева — в браузере; либо `artpush call` по операции из
`artpush contract`, с тем же правилом: сначала сказать человеку, что сделаешь, и дождаться «да».

## Ошибки

- Команды каталогов принимают номер, не имя: найди его в `artpush catalogs tree`. Одинаковых имён может
  быть несколько — уточни у человека, какой нужен.
- `preview_required` (код 2): удаление без `--preview`/`--apply`.
- Код 3: предел ключа не позволяет правку.
