# Удаление и корзина в ArtPush

## Назначение

Удаление в ArtPush обратимо: картина, медиа или каталог уходят в корзину и восстанавливаются оттуда.
Окончательное удаление (очистка корзины) агенту **недоступно** — только человеку в браузере.
Общие правила, коды выхода и ключ — в скилле `artpush`.

## Удалить картину

```sh
artpush painting delete 184            # без --yes: только показывает, что уйдёт в корзину
artpush painting delete 184 --yes      # после явного «да» человека
```

Порядок: вызов без `--yes` → покажи человеку номер, название, сколько файлов → «Удалить № 184 «…» в
корзину? (да / нет)» → только после «да» — с `--yes`. Несколько картин — список целиком и один вопрос,
затем `--yes` по каждой. Удаление каталога — в скилле `artpush-catalogs` (с предпросмотром).

## Корзина

```sh
artpush trash list --table
artpush trash restore --painting 184
artpush trash restore --media 502
artpush trash restore --catalog 12
```

Восстановление подтверждения не требует: оно ничего не уничтожает.

## Очистка корзины — нет

Человек просит «очисти корзину», «удали навсегда» — ответь, что агенту это недоступно намеренно: пусть
сделает в браузере (Корзина → «Удалить навсегда…»). Не пытайся обойти через `artpush call`: система отклонит
операцию (код 3, `forbidden_operation`).

## Ошибки

- Код 3: ключ только для чтения или операция запрещена агенту — остановись, объясни человеку.
- `not_found` (код 1): уже удалено или номер неверен — проверь `artpush trash list`.
