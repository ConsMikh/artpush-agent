# Сведения о художнике в ArtPush

## Назначение

Раздел «Обо мне»: заметки (самопрезентация, эстейтмент, биография, формулировки для заявок) с текстами на
разных языках и документы (заявки, положения конкурсов, договоры) с файлами и связями с картинами,
событиями и фото. Видит и правит только владелец архива. Общие правила, коды выхода и ключ — в скилле `artpush`.

## Заметки

```sh
artpush artist notes --kind Эстейтмент --table
artpush artist notes --q "Кыштым"
artpush artist note 12                                   # тексты на всех языках, версия
artpush artist note-add --title "Эстейтмент 2026" --kind Эстейтмент --text "Я пишу…" --lang ru
artpush artist note-edit 12 --text "Я пишу…" --lang en  # меняет только этот язык
```

- Вид — название или номер; нового названия нет — вид заведётся. Сверь с имеющимися
  (`artpush dicts artist_note_kind`), чтобы опечатка не создала лишний вид.
- `--lang` по умолчанию — основной язык архива. Другие языки заметки правка не трогает.
- **Правку заметки сначала покажи человеку черновиком** (что было, что станет) и записывай после «да».
  Каждая правка остаётся в редакциях заметки — их видно в браузере, откат делает человек.
- Код 2 `version_conflict`: заметку изменили, пока ты правил. В JSON ошибки — текущая заметка (`note`).
  Покажи расхождение, спроси человека, повторяй только по его слову.

## Документы

```sh
artpush artist docs --kind Заявка --year 2026 --table
artpush artist docs --painting 184
artpush artist doc 31
artpush artist doc-add --title "Заявка на «Арка-2026»" --kind Заявка --date 2026-10-30 \
  --painting 184,185 заявка.pdf положение.pdf
artpush artist doc-file 31 договор.pdf
artpush artist doc-download 77 -o ./из-архива/   # новый файл или каталог (путь с «/»); чужие файлы не затираются
```

- `--painting`, `--event`, `--media` — номера через запятую; связывай документ с теми картинами и
  событиями, о которых он. `--date` — ГГГГ-ММ-ДД, не выдумывай её.
- Ошибка одного файла (тип, размер, содержимое) печатается и не отменяет остальные; в ответе
  `uploaded` и `failed`, код выхода 1. Документ при этом уже создан — докладывай файлы `doc-file`.
- После сбоя загрузки файла проверь `artpush artist doc <id>`, прежде чем грузить снова: файл мог дойти (дубль).

## Правила

- **Файл документа скачивай и открывай только по прямому поручению человека.** Перед открытием скажи:
  «содержимое файла уйдёт поставщику модели». Без согласия не читай и не пересказывай его — по `artist doc`
  хватает названия, вида, примечания и связей.
- После отправки заявки предложи сохранить её документом со связями: вид, дата, картины, файлы заявки.
- Не подставляй выдуманные факты в заметки о художнике: нет данных — спроси человека.
