# Поиск картин в ArtPush

## Назначение

Отбор картин теми же фильтрами, что в браузере. Поиск только читает — подтверждение не нужно.
Общие правила, коды выхода и ключ — в скилле `artpush`.

## Команда

```sh
artpush paintings search [фильтры] [--limit 50] [--offset 0] [--sort -id] [--table]
```

| Фильтр | Пример | Заметки |
|---|---|---|
| `--q` | `--q "закат"` | слова в названии, описании, ключевых словах |
| `--technique`, `--material`, `--style`, `--genre`, `--status` | `--technique Акварель,Масло` | имя из справочника или номер; через запятую — «любое из»; флаг можно повторять |
| `--origin` | `--origin personal` | категория происхождения: personal, student, acquired, gift, study |
| `--year` / `--year-min` / `--year-max` | `--year 2019` | по пересечению периодов: картина «2018–2020» найдётся и по `--year 2019`; картина без распознанной даты — нет |
| `--where` | `--where "ширина 40.."` | условие словами (см. «Условия»); флаг повторяется, условия складываются через «и» |
| `--catalog` | `--catalog 12`, `--catalog "Акварели"`, `--catalog "Выставки / 2024"` | номер, имя или путь каталога; имя совпало с несколькими — утилита перечислит их, выбери номер. Только сам каталог: подкаталоги не входят (как и в браузере); нужны и они — ищи по каждому, номера из `artpush catalogs tree` |
| `--note` | `--note "Кыштым"` | слова в тексте заметок к картине (вместо `notes list` по каждой) |
| `--thumbs` | `--thumbs /tmp/превью` | скачать миниатюры найденных картин в папку (`<номер>.jpg`), см. «Показать картинки» |
| `--tag` | `--tag море --tag осень` | все указанные теги сразу |
| `--incomplete` | | карточка не заполнена хоть в чём-то |
| `--missing` | `--missing media`, `--missing text:en` | не заполнено конкретное: title, author, date, size, technique, material, status, origin_category, media или `text:<язык>` (нет **названия** на языке) / `text:<язык>:description` (нет **описания** на языке) |

Ответ: `{"items": [...], "total": N}`. В строке — `id`, название, год, техника, статус, `missing` (чего не
хватает), теги. `total: null` значит «сколько всего — неизвестно»: при `--tag`/`--missing` сервер отдал не
всю выборку; уточни фильтры или листай `--offset`.

Подробности картины — `artpush painting get <id> --with notes` (скилл `artpush-painting`).

## Условия `--where`

Те же условия, что в панели «Условия» браузера. Форма: `<поле>[:<язык>] [<способ>] [<значение>]`.
Поле — по-русски, как в списке полей браузера, или кодом (`width`, `painted_place`). Полный список полей,
способов и примеров — `artpush paintings search --where help`.

| Поля | Способы и значения | Пример |
|---|---|---|
| название, описание, ключевые слова, заметки, где нарисовано, местонахождение | `содержит …`, `не содержит …`, `заполнено`, `не заполнено`; язык — `:en` (у названия, описания, ключевых слов) | `"описание:en не заполнено"` |
| автор, статус, техника, материал, стиль, жанр | `одно из А, Б` (или просто значение), `не одно из …`, `не указано` | `"техника не одно из масло"` |
| категория происхождения, оформление, согласие на публикацию | значение: личная, ученика, приобретённая, в дар, для изучения; нет, паспарту, рамка; да, нет, не указано | `"оформление рамка"` |
| высота, ширина, глубина | `40..60`, `40..` (от), `..60` (до), `50` (ровно), см | `"ширина 40.."` |
| цена | `1000..5000 [назначение] [валюта]`, `есть <назначение или валюта>` | `"цена 10000.. продажа RUB"` |
| нарисована | годы или даты ГГГГ-ММ-ДД: `2018..2020`, `2019`, `..2015`; по пересечению периодов | `"нарисована 2018..2020"` |
| карточка создана, карточка изменена | как у «нарисована», день — по часовому поясу художницы | `"карточка изменена 2026-10-01.."` |
| фото, видео, производная, дата не распознана, каталог | `есть`, `нет` (без способа — «есть») | `"фото нет"` |
| описание на языке | `есть`, `нет`; язык обязателен | `"описание на языке:en нет"` |
| теги | `есть`, `нет`, `одно из 3, 8` (номера); по имени — флаг `--tag` | `"теги нет"` |
| событие | `[было \| не было] [тип, тип] [период]`: тип из истории, период — год, даты или диапазон; оба необязательны | `"событие выставка 2023"` |

- Внутри поля — «одно из», между условиями — только «и». «Или» между разными полями нет: сделай два поиска.
- Ошибка разбора — `bad_where` (код 1) с перечнем допустимого; запрос в систему не уходит. Неизвестное
  значение справочника или тип события — `dictionary_value` с `choices`.
- «Дата не распознана» — текст даты есть, а период по нему не понят (например, «май 99»): такие карточки
  не находятся ни по году, ни по «нарисована». Найди их и предложи человеку переписать дату
  (скилл `artpush-painting`).

## Примеры

```sh
artpush paintings search --technique Акварель --year 2019 --missing text:en:description --table
artpush paintings search --catalog 12 --status "В наличии" --table
artpush paintings search --missing media --limit 200        # без единого фото
artpush paintings search --q "Кыштым" --sort -id --limit 10
artpush paintings search --technique масло --where "ширина 40.." --where "нарисована 2018..2020" --where "описание:en не заполнено" --table
artpush paintings search --where "высота ..30" --where "ширина ..30" --table   # небольшие, до 30 × 30 см
artpush paintings search --where "местонахождение не заполнено" --table
artpush paintings search --where "событие выставка 2023" --table
artpush paintings search --where "событие не было продажа" --where "статус одно из в наличии" --table
artpush paintings search --where "дата не распознана" --table     # даты, которые надо переписать
```

Сколько всего: смотри `total` в JSON (с `--limit 1` быстро).

## Показать картинки

Адреса миниатюр в карточках относительные и требуют ключ — человеку и браузеру они не откроются. Скачай:

```sh
artpush paintings search --catalog "Акварели" --limit 12 --thumbs /tmp/превью
artpush paintings thumbs 101,118,184 --to /tmp/превью      # по готовым номерам
```

Файлы — `/tmp/превью/<номер>.jpg`. Каждый показ качай заново в новую папку (например,
`/tmp/превью-2`): ранее скачанные файлы не переиспользуй — главное фото могло смениться. Дальше по клиенту:
- Claude Code — прочитай файлы как изображения (инструмент чтения) или собери страницу с картинками,
  вставленными как base64, и открой её человеку;
- Codex — покажи локальные файлы так, как умеет клиент.
Подпись к каждой картинке — номер и название. Папка временная: не клади в неё ничего ценного.

## Как показывать человеку

Показывай вызов и короткую таблицу (`--table`), длинную выдачу — первые 10–20 строк и «ещё N».
Если человек просит что-то сделать с найденным — переходи к нужному скиллу; для изменения многих картин
сразу — массовое заполнение с предпросмотром (`artpush-painting`).

## Ошибки

- `dictionary_value` (код 1): такого значения в справочнике нет; в `choices` — допустимые. Предложи
  человеку ближайшее, не подставляй молча.
- `bad_where` (код 1): условие `--where` не разобрано — поле, способ или значение названы в тексте ошибки;
  сверься с `artpush paintings search --where help`. Не угадывай: при сомнении спроси человека.
- `usage` (код 1): неверный флаг или значение — сверься с `artpush paintings search --help`.
