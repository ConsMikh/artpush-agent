# ArtPush: архив картин через утилиту `artpush`

## Назначение

ArtPush — личный архив картин: карточки, тексты на языках, цены, фото и видео, каталоги, заметки, история.
Агент работает с ним только через утилиту командной строки `artpush` с ключом пользователя. Этот скилл —
вход: подключение, правила, которые действуют всегда, и к какому скиллу идти за конкретной задачей.

## Подключение

```sh
artpush whoami --table     # кто я, роль, предел ключа (read / write / admin)
artpush contract           # версия системы, контракт, темп
```

- Утилиты нет — выполни команду установки сам (ключ не нужен):
  - macOS и Linux: `curl -fsSL https://raw.githubusercontent.com/ConsMikh/artpush-agent/main/install.sh | sh`
  - Windows (для bash и PowerShell, не для cmd.exe): `powershell -NoProfile -Command 'irm https://raw.githubusercontent.com/ConsMikh/artpush-agent/main/install.ps1 | iex; exit $LASTEXITCODE'`
    (человек в своём окне PowerShell вводит просто `irm https://raw.githubusercontent.com/ConsMikh/artpush-agent/main/install.ps1 | iex`).

  Покажи человеку итог установки. Если команда `artpush` после установки не находится — попроси
  человека открыть терминал и тебя заново. Подробная инструкция — https://github.com/ConsMikh/artpush-agent.
- Ключа нет (`artpush whoami` отвечает кодом 1 или 3 про ключ) — попроси человека выпустить ключ в ArtPush
  (Настройки → Ключи агента), затем в своём окне терминала (macOS: Программы → Утилиты → Терминал;
  Windows: Пуск → «PowerShell») выполнить `artpush init`: утилита спросит адрес (Enter —
  `https://artpush.fammix.org`) и ключ скрытым вводом. Сам `artpush init` не запускай — скрытому вводу нужно
  окно терминала человека. Когда человек закончит — проверь `artpush whoami`.
  Ключ в чат не принимай; прислали — не повторяй его и предложи отозвать и выпустить новый.
- Ключ хранится в `~/.config/artpush/credentials` или в переменной `ARTPUSH_TOKEN`. Никогда не печатай
  и не пересказывай ключ, не вставляй его в команды.
- Утилита отвечает JSON в stdout, сообщения — в stderr. Для показа человеку добавляй `--table`.
- Справка по любой команде: `artpush <команда> --help`.

## Правила (всегда)

1. **Подтверждение.** Необратимое и массовое делается в два шага: `--preview` → покажи человеку, что
   изменится (таблицей), → спроси «Применить? (да / нет)» → только после явного «да» `--apply <жетон>`.
   Молчание, «наверное» и «сам реши» — это не «да». Жетон живёт 10 минут и привязан к выборке.
2. **Жетон одноразовый.** После любой ошибки применения жетон сгорел: заново `--preview`, заново показ
   и вопрос.
3. **Удаление в корзину** — `artpush painting delete <id>` без `--yes` только показывает, что будет;
   `--yes` — после «да» человека.
4. **Очистки корзины нет.** Окончательное удаление агенту недоступно — только в браузере. Не ищи обходов
   через `artpush call`.
5. **Не решай за человека** спорное: дубли, конфликт версий, выбор каталога, перезапись чужой правки.
6. **Показывай работу**: вызовы команд видны человеку, результаты — таблицей, в конце итог одной строкой
   («Итог: изменено 2, пропущено 1 (№ 187 — конфликт)»).

## Коды выхода и что делать

| Код | Значит | Действие |
|---|---|---|
| 0 | успех | дальше |
| 1 | прочая ошибка (сеть, неверные аргументы, нет такого значения) | прочитай `error` в JSON, поправь вызов; `choices` подскажет допустимые значения |
| 2 | конфликт версии (409) или нужен предпросмотр | 409: покажи человеку расхождение (`field`, `by`, `at`, `their_label`, `mine_label`) и спроси, записать поверх или оставить; поверх — та же команда с `--overwrite` после «да», молча не повторяй. `preview_required`: сделай `--preview` |
| 3 | нет прав, ключ не действует | остановись. Предел ключа мал — скажи, какой нужен. Ключ отключён, просрочен или отозван — попроси человека выпустить новый в ArtPush |
| 4 | темп превышен | утилита уже ждала сама (до трёх повторов); подожди минуту и продолжи медленнее |
| 5 | контракт системы не совпадает с утилитой | остановись, изменяющих команд не выполняй; предложи человеку `artpush update` |

Темп: 120 запросов и 60 загрузок файлов в минуту на ключ. При 429 утилита ждёт `Retry-After` сама.

## К какому скиллу идти

| Задача | Скилл |
|---|---|
| найти, отобрать, посчитать картины; незаполненные | `artpush-search` |
| карточка, поля, тексты на языках, цены, теги; массовое заполнение | `artpush-painting` |
| фото и видео картины: загрузка, скачивание, порядок, главное, перенос | `artpush-media` |
| каталоги, серии, дерево, кто в каком каталоге | `artpush-catalogs` |
| импорт папки с фото, «разложи фотографии по картинам», Artnow | `artpush-import` |
| заметки, история изменений, события задним числом | `artpush-notes-history` |
| удалить, восстановить, корзина | `artpush-trash` |
| справочники, журнал, целостность, ключи, пользователи (администратор) | `artpush-admin` — только в основном проекте ArtPush |

Операции без отдельной команды — `artpush call <METHOD> <путь>` по контракту (`artpush contract`);
правила подтверждения действуют и для них.

## Обновление

После выпуска новой версии ArtPush, при предупреждении «набор …, система …» или при коде 5:
`artpush update` — ставит из зеркала выпуск версии системы (утилиту и скиллы); ключ и настройки остаются.

- macOS и Linux: обновление идёт на месте; после него открой сеанс заново, чтобы подхватить новые скиллы.
- Windows: команда сразу отвечает `{"updated": "started", …}`, а установка идёт в отдельном окне. Скажи
  человеку: дождаться в том окне «Готово», нажать Enter и открыть агента заново. До этого утилитой не пользуйся.
- Выпуска версии системы в зеркале нет (код 1, «В зеркале выпуска … нет») — сообщи человеку, это вопрос
  к администратору ArtPush.
