# Фото и видео картины в ArtPush

## Назначение

Медиафайлы одной картины: загрузка, скачивание, порядок, главное, перенос между картинами.
Общие правила, коды выхода и ключ — в скилле `artpush`. Много фото, которые ещё не разложены по картинам, —
это импорт папки (`artpush-import`), а не загрузка по одному.

## Посмотреть файлы

```sh
artpush painting get 184 --table      # в карточке список media: id, имя, is_main
```

## Загрузка и скачивание

```sh
artpush media upload 184 ~/фото/закат-1.jpg ~/фото/закат-2.jpg
artpush media download 184 --all --to ~/Загрузки/184
artpush media download 184 --media 11 --thumbnail --to /tmp/превью
```

- Файлы грузятся по одному, сбой сети и 5xx утилита повторяет сама. Темп загрузок — 60 в минуту на ключ;
  при 429 утилита ждёт сама.
- Сервер может отклонить файл (дубль, неподдерживаемый формат) — причина в выводе; перескажи человеку.
- Скачивание не перезаписывает файлы в папке: занятое имя получает номер медиа впереди.

## Порядок и главное фото

```sh
artpush media order 184 12,11,13      # полный новый порядок номеров медиа
artpush media main 184 12
```

Без подтверждения: это обратимо и делается по прямой просьбе.

## Перенос в другую картину — только с подтверждением

```sh
artpush media transfer --ids 12,13 --to 187 --preview --table
artpush media transfer --ids 12,13 --new --catalog 5 --preview --table   # в новую картину
# показать человеку план: какие файлы, откуда, куда; спросить «Перенести? (да / нет)»
artpush media transfer --ids 12,13 --to 187 --apply pv_…
```

- `--apply` — с теми же `--ids` и `--to`/`--new`, что в preview, и только после явного «да».
- Жетон одноразовый, 10 минут; после ошибки — новый `--preview` и новый вопрос.

## Ошибки

- `preview_required` (код 2): вызвал перенос без `--preview`/`--apply` — начни с `--preview`.
- Код 2 с `conflict`: картину изменили параллельно — покажи человеку и спроси.
- Код 3: ключ только для чтения или чужая картина — остановись и скажи человеку.
