# Импорт картин в ArtPush: папка и Artnow

## Назначение

Импорт создаёт картины из файлов пачкой: файлы загружаются в сеанс, система раскладывает их на группы
(группа = будущая картина), человек проверяет разбор, и только после его «да» картины создаются.
Общие правила, коды выхода и ключ — в скилле `artpush`.

## Импорт папки: порядок действий

**1. Каталог назначения.** Спроси, в какой каталог класть картины, если человек не сказал. Посмотри
`artpush catalogs tree --table`. Каталога нет — создай (`artpush catalog add "Имя"`) или передай
`--new-catalog "Имя"` в `import folder`. Один каталог с таким именем — можно по имени, несколько — по номеру.

**2. Загрузка и разбор** (картины на этом шаге не создаются):

```sh
artpush import folder ~/Картины/Выставка-2024 --catalog "Выставка 2024" --origin personal --table
```

- Общие данные пачки (`--author`, `--technique`, `--material`, `--status`, `--origin`, `--framing`,
  `--location`, `--tag`, `--catalog`) не указаны — берутся умолчания из настроек человека. Нет категории
  происхождения в настройках — утилита попросит `--origin`; спроси человека, какую.
- Принимаются фото (JPEG, PNG, TIFF, WebP, HEIC, AVIF), RAW камер (DNG, CR2, CR3, NEF, ARW, ORF, RAF,
  RW2, PEF), PSD и видео — как есть, оригинал хранится без изменений.
- Скрытые и служебные файлы пропускаются. Загрузка идёт по одному файлу, темп 60 в минуту — большая
  папка грузится долго; утилита пишет прогресс в stderr, повторы при сбоях делает сама.

**3. Проверка разбора.** В ответе — `session`, `groups` (у каждой `id`, `name`, `files`, `skipped`,
`matches_painting`), `singles`, `duplicates`, `warnings`, `preview_token`. Правила системы:
- подпапка с файлами — одна картина, название — имя подпапки;
- файл прямо в корне папки — отдельная картина, название — имя файла;
- файл, который уже есть в архиве (`exists_in` — номер картины), помечен как пропускаемый;
  группа, полностью совпадающая с существующей картиной, — `matches_painting`.

**4. Перегруппировка — когда разбор не совпадает с картинами.** Типичный случай — плоская папка, где фото
одной картины различаются по имени (`закат-1.jpg`, `закат-2.jpg`, `люпин.jpg`): система сделала по
картине на файл. Сгруппируй по именам сам:

```sh
artpush import regroup 41 --move 502,503 --to new     # файлы 502, 503 — в новую группу
artpush import regroup 41 --move 504 --to 77          # файл 504 — в группу 77
artpush import rename 41 77 "Закат на озере"          # название картины
artpush import skip 41 78                             # группу не создавать (--undo — вернуть)
```

Каждая из этих команд отвечает свежим разбором с новым жетоном. Если группировка неочевидна — предложи
человеку план до перекладывания.

**5. Показать человеку и спросить.** Таблица: группа → название → файлы, отдельно — пропуски и дубли
(«3 файла уже есть в архиве: № 184, 187»), предупреждения. Вопрос: «Создать N картин в каталоге «…»?
(да / нет / поправить)».

**6. Создание — только после «да»:**

```sh
artpush import review 41 --table           # если после показа прошло время: свежий жетон
artpush import create 41 --apply pv_…
```

`import create` ждёт окончания и отвечает итогом (`result`). Итог человеку одной строкой: «Создано 12
картин в «Выставка 2024», пропущено 3 дубля».

## Оборвалось — продолжить

Сеть, Ctrl-C, код 4 или `upload_incomplete` — повтори **ту же** команду с тем же путём:

```sh
artpush import folder ~/Картины/Выставка-2024
```

Утилита найдёт незавершённый сеанс с тем же набором файлов и догрузит недостающее (общие флаги к
продолжаемому сеансу не применяются — список в `ignored_flags`). `import create` прервался или вышел по
таймауту — проверь `artpush import sessions --table`; при `import_failed` повтори `import create` с новым
жетоном из `import review`.

## Незавершённые сеансы

```sh
artpush import sessions --table
artpush import review 41 --table
artpush import discard 41 --preview          # отказаться от сеанса: показать человеку, что пропадёт
artpush import discard 41 --apply pv_…       # только после «да»
```

## Artnow

```sh
artpush artnow check https://artnow.ru/…          # проверить ссылку на страницу художника
artpush artnow start https://artnow.ru/… --origin personal
artpush artnow works 52 --table                   # прочитанные работы
artpush artnow create 52 --apply pv_…             # после показа разбора и «да»
```

- «Artnow» к работам импорта добавляется сам — `--catalog "Artnow"` не нужен. Разложить работы по
  своим каталогам — на шаге «Разбор» в браузере; либо `--catalog <каталог>` для всех работ сразу.
- `artnow start` читает работы (может идти долго), затем печатает разбор с жетоном — дальше как с папкой:
  показать, спросить, `artnow create … --apply`.
- Чтение остановилось (`crawl_stopped`) — `artpush artnow resume 52`; ушло по таймауту —
  `artpush artnow wait 52`; остановить — `artpush artnow stop 52`.
- Этот аккаунт уже импортировали — система откажет; повторный импорт (`--confirm-rerun`) только после
  вопроса человеку.

## Ошибки

- `preview_required` / жетон отклонён (код 2): разбор изменился или жетон сгорел — `import review`,
  снова показать человеку изменения, снова спросить.
- `catalog_not_found` / `catalog_ambiguous` (код 1): создай каталог или уточни номер у человека.
- `session_discarded`: сеанс отменили (например, в браузере) — начни импорт заново, спросив человека.
- Код 3 на загрузке: ключ без правки или отозван — остановись.
